================================================================================
                          PAȘI SETUP RAPID
================================================================================

Pasul 1: Google Sheets API (2 min)
- Mergi pe https://console.cloud.google.com/
- New Project → "Medical"
- Enable APIs → "Google Sheets API"
- Credentials → Create API Key
- Copiază cheia

Pasul 2: Google Sheets Public (1 min)
- Deschide Google Sheets-ul
- Share → "Anyone with the link"
- Copiază ID din URL

Pasul 3: Actualizează repartizare.html (1 min)
- Deschide fișierul
- Înlocuiește GOOGLE_SHEETS_ID și GOOGLE_API_KEY
- Salvează

Pasul 4: Deschide în Browser (1 min)
- Deschide repartizare.html în browser
- Introdu Discord ID-ul tău
- Click "Conectare"
- Selectează o zonă
- Gata!

================================================================================
                          WEBHOOK DISCORD
================================================================================

Dacă vrei notificări pe Discord:

1. Creează Cloudflare Worker (5 min)
   - Copiază codul din cloudflare-worker.js
   - Creează pe https://dash.cloudflare.com/
   - Deploy

2. Creează Discord Webhooks (5 min)
   - Webhook 1: Repartizare Zone
   - Webhook 2: Loguri Arondare

3. Adaugă URLs în Cloudflare Worker
   - Înlocuiește WEBHOOK_REPARTIZARE
   - Înlocuiește WEBHOOK_LOGURI

4. Salvează Worker URL în localStorage
   - localStorage.setItem('workerUrl', 'https://...')

================================================================================
                          TROUBLESHOOTING
================================================================================

"Utilizator nu găsit"
→ Verifică Discord ID în Google Sheets (coloana T)

"CORS error"
→ Google Sheets trebuie public
→ API Key trebuie validă

Webhook nu funcționează
→ Verifică URL-ul webhook-ului
→ Canalul Discord trebuie să existe
→ Bot trebuie să aibă permisiuni

Datele nu se încarcă
→ Verifică Sheets ID
→ Verifică API Key
→ Verifică dacă Sheet1 e numele corect
